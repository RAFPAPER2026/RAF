### 交付物检查规程

对不同类型的交付物，必须采用对应的检查方式，确保不仅看到文件存在，还能验证其内容/排版/交互是否符合要求。

#### PPT / .pptx

- 必须使用 `pptx` skill 将幻灯片渲染为图片后检查排版与视觉效果，不能仅凭文本提取判断。
- 推荐流程：调用 `pptx` skill 的 `scripts/thumbnail.py` 将 `.pptx` 渲染为逐页图片，逐一查看页面布局、文字与图表位置、配色与可读性。
- 如需提取文字内容做内容核对，可使用 `pptx` skill 的 `markitdown` 提取文本，但排版判断仍以渲染图片为准。

#### HTML / .html

- 必须使用 `webapp-testing` skill（基于 Playwright）以浏览器方式打开本地 HTML 文件（使用临时轻量静态服务器托管网页，开启在线动态加载），进行交互与截图后判断，不能仅凭网页源码判断。如因CDN等原因导致网页图表等渲染失败，不应该归为视觉瑕疵，在评价时将相关rubric叶子标记为正确，理由说明实际情况，如实在exception中报告异常。
- 推荐流程：用 `webapp-testing` skill 启动浏览器 → 打开结果目录下的 HTML 文件 → 对关键交互（点击、输入、悬停等）逐项尝试 → 截图保存视觉状态 → 基于截图、交互结果和页面源代码综合判断页面是否满足要求。

#### PDF / .pdf

- 使用 `pdf` skill 读取/提取 PDF 内容；如需排版核对，渲染为图片查看。

#### DOCX / .docx

- 使用 `docx` skill 提取文本与结构；如需排版核对，渲染为图片查看。

#### XLSX / .xlsx

- 使用 `xlsx` skill 提取单元格数据、公式与图表；如需排版核对，渲染为图片查看。

#### 其他文件类型

- 文本/代码/JSON 等可直接用 `Read` 查看。
- 图片可直接用 `Read` 查看。
