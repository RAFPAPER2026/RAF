### 第 1 题

**题目**：下面哪个是 Python 中正确的注释写法？

**选项**：
- A. # 这是一行注释 ✅（正确答案）
- B. // 这是一行注释
- C. /* 注释 */
- D. -- 注释

**解析**：Python 使用 # 作为单行注释符号，与 Perl/Bash/Ruby 等语言相同。// 是 Java/JS 的注释，/* */ 是 C/JS 的多行注释，-- 是 SQL 的注释。

**结果**：✅ 正确

### 第 2 题

**题目**：以下哪个数据类型是不可变的（immutable）？

**选项**：
- A. list（列表）
- B. dict（字典）
- C. set（集合）
- D. tuple（元组） ✅（正确答案）

**解析**：tuple（元组）是 Python 中的不可变数据类型，创建后不能修改其元素。list、dict、set 都是可变的，可以随时添加、删除或修改元素。

**结果**：✅ 正确

### 第 4 题

**题目**：下列哪个运算符表示「不等于」？

**选项**：
- A. != ✅（正确答案）
- B. <>
- C. ~=
- D. /=

**解析**：Python 中「不等于」运算符是 !=。&lt;&gt; 是 Python 2 时代的写法（已废弃），~= 不是标准的不等于运算符，/= 是除法赋值运算符。

**结果**：✅ 正确

### 第 5 题

**题目**：len() 函数不能直接用于以下哪个类型？

**选项**：
- A. str（字符串）
- B. list（列表）
- C. dict（字典）
- D. int（整数） ✅（正确答案）

**解析**：int（整数）是标量类型，没有长度概念。len() 可以用于 str、list、dict、set、tuple 等可迭代或拥有 __len__ 方法的对象。

**结果**：✅ 正确

### 第 6 题

**题目**：以下哪个是正确的列表推导式（list comprehension）？

**选项**：
- A. [x for x in range(5)] ✅（正确答案）
- B. (x for x in range(5))
- C. {x for x in range(5)}
- D. 

**解析**：列表推导式的语法是 [表达式 for 变量 in 可迭代对象]，用方括号包裹。(x for x in ...) 是生成器表达式（返回迭代器），{x for x in ...} 是集合推导式。

**结果**：✅ 正确

### 第 7 题

**题目**：Python 中，'Hello' + 'World' 的结果是？

**选项**：
- A. 'HelloWorld' ✅（正确答案）
- B. 'Hello World'
- C. 报错
- D. None

**解析**：在 Python 中，字符串使用 + 运算符执行拼接操作，结果为 'HelloWorld'（无空格）。如需空格，需要显式添加，如 'Hello ' + 'World'。

**结果**：✅ 正确

### 第 9 题

**题目**：执行 bool('') 和 bool(' ') 的结果分别是？

**选项**：
- A. False, False
- B. False, True ✅（正确答案）
- C. True, False
- D. True, True

**解析**：空字符串 '' 在布尔上下文中为 False，而包含一个空格的字符串 ' ' 不是空字符串，因此为 True。任何非空字符串（即使只有空格或换行）都为 True。

**结果**：✅ 正确

### 第 10 题

**题目**：以下哪个方法可以向列表末尾添加元素？

**选项**：
- A. list.add()
- B. list.append() ✅（正确答案）
- C. list.insert()
- D. list.push()

**解析**：list.append() 用于向列表末尾添加单个元素，是最常用的方法。list.add() 是 set 的方法，list.insert() 在指定位置插入，list.push() 不是列表的标准方法（deque 才有）。

**结果**：✅ 正确
