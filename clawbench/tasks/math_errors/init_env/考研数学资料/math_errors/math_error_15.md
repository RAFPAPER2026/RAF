# 条件极值拉格朗日乘数法
- 科目：高等数学
- 难度：中等
- 常见错误率：40%

## 题目

求函数 $f(x,y) = xy$ 在约束条件 $x + y = 1$ 下的极值。

## 常见错误

**错误一**：从约束条件解出 $y = 1 - x$ 代入 $f(x,y)$，然后对 $x$ 求导令其为0：

$g(x) = x(1-x) = x - x^2$

$g'(x) = 1 - 2x = 0$，得 $x = \frac{1}{2}$

但忘记验证这是极大值还是极小值，也忘记说明这是条件极值而非无条件极值。

**错误二**：使用拉格朗日乘数法时，构造拉格朗日函数时符号错误：

$$L = xy - \lambda(x + y - 1)$$

求偏导时漏项或符号写错。

**错误三**：求出驻点后未判断极大极小，直接写"极值为 $\frac{1}{4}$"。

## 错误原因分析

1. 代入法虽然可行，但当约束条件复杂或变量多时难以操作，拉格朗日乘数法更通用
2. 拉格朗日函数的构造方式（加还是减 $\lambda$）不影响结果，但偏导求解时容易符号出错
3. 条件极值的极大极小判断常被忽略

## 正确解法

**拉格朗日乘数法**

构造拉格朗日函数：

$$L(x, y, \lambda) = xy + \lambda(1 - x - y)$$

对各变量求偏导并令其为0：

$$\frac{\partial L}{\partial x} = y - \lambda = 0 \quad \Rightarrow \quad y = \lambda$$

$$\frac{\partial L}{\partial y} = x - \lambda = 0 \quad \Rightarrow \quad x = \lambda$$

$$\frac{\partial L}{\partial \lambda} = 1 - x - y = 0 \quad \Rightarrow \quad x + y = 1$$

由前两式得 $x = y$，代入第三式：$2x = 1$，$x = \frac{1}{2}$，$y = \frac{1}{2}$。

**判断极大极小**

在约束 $x + y = 1$ 上，$f(x, 1-x) = x(1-x) = x - x^2$。

$g''(x) = -2 < 0$，故 $x = \frac{1}{2}$ 处为**极大值**。

$$f_{\max} = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$$

## 易错点总结

拉格朗日乘数法求出驻点后需判断极大极小；偏导求解时注意符号一致性。
