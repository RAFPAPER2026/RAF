# 二重积分交换积分次序
- 科目：高等数学
- 章节：第六章 重积分
- 难度：中等
- 常见错误率：42%

## 题目

交换积分次序：$\int_0^1 dx \int_x^{2-x^2} f(x,y) \, dy$。

## 常见错误

**错误一**：直接将内外积分变量互换，写成 $\int_x^{2-x^2} dy \int_0^1 f(x,y) \, dx$，内积分上限含外积分变量，逻辑混乱。

**错误二**：画积分区域时边界曲线判断错误，将 $y = 2 - x^2$ 与 $y = x$ 的交点求错，导致区域划分不正确。

## 错误原因分析

1. 未画出积分区域的图形，仅凭代数表达式难以准确确定区域边界
2. 交换积分次序需要重新确定内外积分的上下限，这需要对区域进行重新分割
3. 本题区域需要分成两部分（$0 \leq y \leq 1$ 和 $1 \leq y \leq 2$），容易遗漏

## 正确解法

**第一步：确定积分区域**

原积分区域 $D$：$0 \leq x \leq 1$，$x \leq y \leq 2 - x^2$。

边界曲线：$y = x$（直线），$y = 2 - x^2$（抛物线），$x = 0$，$x = 1$。

**第二步：求交点**

$y = x$ 与 $y = 2 - x^2$ 的交点：$x = 2 - x^2$，即 $x^2 + x - 2 = 0$，$(x+2)(x-1) = 0$，得 $x = 1$（$x = -2$ 舍去），交点为 $(1, 1)$。

**第三步：重新确定上下限**

先对 $x$ 积分，需将区域分为两部分：

- 当 $0 \leq y \leq 1$ 时：$0 \leq x \leq y$
- 当 $1 \leq y \leq 2$ 时：$0 \leq x \leq \sqrt{2 - y}$

因此：

$$\int_0^1 dx \int_x^{2-x^2} f(x,y) \, dy = \int_0^1 dy \int_0^y f(x,y) \, dx + \int_1^2 dy \int_0^{\sqrt{2-y}} f(x,y) \, dx$$

## 易错点总结

交换积分次序必须先画图确定区域，再根据新次序重新划分区域并确定上下限，不能直接互换变量。
