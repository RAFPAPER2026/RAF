# 矩阵乘法不可交换性相关错误
- 科目：线性代数
- 章节：第二章 矩阵
- 难度：基础
- 常见错误率：35%

## 题目

设 $A$, $B$ 均为 $n$ 阶方阵，判断以下等式是否成立：

(1) $(A + B)^2 = A^2 + 2AB + B^2$

(2) $(A + B)(A - B) = A^2 - B^2$

(3) $(AB)^2 = A^2 B^2$

## 常见错误

三个等式全部判断为成立，套用数的运算公式。

## 错误原因分析

1. 将数的乘法运算律直接迁移到矩阵乘法，忽略了矩阵乘法一般不满足交换律：$AB \neq BA$
2. $(A+B)^2 = (A+B)(A+B) = A^2 + AB + BA + B^2$，只有当 $AB = BA$ 时才有 $AB + BA = 2AB$
3. 习惯了实数运算的"自动交换"，对矩阵运算的特殊性缺乏警觉

## 正确解法

**(1) $(A + B)^2 = A^2 + 2AB + B^2$ — 不成立**

$$(A+B)^2 = (A+B)(A+B) = A^2 + AB + BA + B^2$$

一般情况下 $AB \neq BA$，故 $AB + BA \neq 2AB$。

只有当 $AB = BA$ 时等式才成立。

**(2) $(A + B)(A - B) = A^2 - B^2$ — 不成立**

$$(A+B)(A-B) = A^2 - AB + BA - B^2$$

一般情况下 $-AB + BA \neq 0$。

只有当 $AB = BA$ 时等式才成立。

**(3) $(AB)^2 = A^2 B^2$ — 不成立**

$$(AB)^2 = ABAB$$

一般情况下 $ABAB \neq AABB = A^2B^2$。

只有当 $AB = BA$ 时等式才成立。

## 易错点总结

矩阵乘法不满足交换律，数的乘法公式（完全平方、平方差等）不能直接套用于矩阵，展开时必须严格按顺序相乘。
