# 定积分换元时忘记改变上下限
- 科目：高等数学
- 章节：第三章 不定积分与定积分
- 难度：基础
- 常见错误率：38%

## 题目

计算定积分 $\int_0^4 \frac{1}{1 + \sqrt{x}} \, dx$。

## 常见错误

令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t \, dt$。

代入得：

$$\int_0^4 \frac{2t}{1 + t} \, dt$$

**错误**：积分上下限仍用原来的0和4，计算：

$$\int_0^4 \frac{2t}{1+t} dt = 2\int_0^4 \frac{t}{1+t} dt = 2\int_0^4 \left(1 - \frac{1}{1+t}\right) dt = 2[t - \ln(1+t)]_0^4 = 2(4 - \ln 5)$$

## 错误原因分析

1. 定积分换元时，积分上下限必须随新变量一起变化，这是初学者最容易忽略的步骤
2. 混淆了不定积分和定积分的换元：不定积分换元后需要回代，定积分换元后只需改变上下限
3. 当 $x = 0$ 时 $t = 0$，当 $x = 4$ 时 $t = 2$，上下限应变为 $0$ 到 $2$

## 正确解法

令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t \, dt$。

当 $x = 0$ 时 $t = 0$；当 $x = 4$ 时 $t = 2$。

$$\int_0^4 \frac{1}{1+\sqrt{x}} dx = \int_0^2 \frac{2t}{1+t} dt = 2\int_0^2 \left(1 - \frac{1}{1+t}\right) dt$$

$$= 2[t - \ln(1+t)]_0^2 = 2(2 - \ln 3) = 4 - 2\ln 3$$

## 易错点总结

定积分换元必须同时改变上下限：新下限=旧下限对应的t值，新上限=旧上限对应的t值。
